## 1. 现在哪儿坏了、不改会怎样

现在的插件只会管阅读清单，标签页一个都碰不了：你开着的 174 个标签页，助手只能读会话文件猜，没法替你分组或收起（[U-DIAG-1|3937]）。不改的话，每多一种浏览器里的东西要整理，就得再写一个一次性插件。

### 核心概念

- **能力开关**：插件弹窗里的一个勾选框，管一类浏览器里的东西。例：勾上「标签页与标签组」，助手才能替你建分组；取消后，助手再调用会被插件当场拒绝。
- **浏览器授权**：Chrome 给插件的权限。例：第一次勾「历史记录」时 Chrome 弹窗问你「允许读取浏览历史吗」，你点拒绝，开关就弹回关闭。

### 页面示意

点工具栏上的插件图标，弹出下面这个小面板。布局是一列开关，每个开关一句说明；顶部一行显示和助手的连接状态。勾选时 Chrome 会弹出自己的授权确认框，拒绝则开关弹回；取消勾选会同时交还授权。

## 3. 撤不回来的与会变的

撤不回来的有两件，都要你当场点头。第一件是网上仓库改名（[U-GATE-1|8b96]）。第二件是改你本机的助手配置，让它每次都现问插件开了哪些能力，不再缓存一天（[U-GATE-2|c8fa]）。改前会备份原配置。

会变的有六处。标签页能力的具体动作，包括关标签页前存备份，见（[U-BEH-1|5e08]），书签和历史的具体动作见（[U-BEH-2|9b04]）。插件多了一个弹窗；阅读清单的授权和现在一样装插件时就有，它的开关只管给不给助手用，另外三项勾选时才要授权（[U-BEH-3|47eb]）。开关变化会实时告诉助手，并记在本机，下次启动直接生效（[U-BEH-4|b2d6]）。关着的能力，或授权已被你在浏览器设置里收回的能力，插件当场拒绝；新旧版本混着用时阅读清单照常能用（[U-BEH-5|fee9]）。名字和配置目录换新，旧目录自动搬过去（[U-BEH-6|6e7b]）。

## 6. 最可能翻车的假设

「标签页、书签、历史三项授权能等勾选时再要」已经查实：Chrome 官方文档列出的例外里没有它们，装上后勾选时会真的弹授权框再确认一次；阅读清单因为默认就开，授权改为装插件时就拿，和现在一样（[U-SPK-1|f5cb]）。其次是「助手在会话中途能看到新开的能力」：接受风险，不行就新开一个会话，开关已记在本机（[U-SPK-2|3e32]）。最后是「改名后旧的安装地址还能用」：接受风险，改名当天同步改本机配置（[U-SPK-3|ea6f]）。

## 7. 已定死不用你看的

你拍了三件事：在原仓库上直接改名（[U-DEC-1|abc9]）；新插件默认只开阅读清单（[U-DEC-2|5fe2]）；助手能关标签页，关之前先存备份，也能按备份重新打开（[U-DEC-3|4b6e]）。

阅读清单的六个工具名字和用法一个不改（[U-CTR-1|d637]）。插件身份编号不变，不用重新配对（[U-CTR-2|3967]）。只在本机通信、网页无法冒充插件这条安全线不动（[U-CTR-3|d075]）。端口不变，新旧插件和服务混着用时阅读清单照常能用（[U-CTR-4|6e35]）。
